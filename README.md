# Site — Autojade

`EMPRESA` Autojade

`STACK` Next.js • React • TypeScript • Tailwind CSS

`URL` [autojade.com.br](https://autojade.com.br)

Site institucional e comercial da **Autojade**, desenvolvido em Next.js e hospedado em produção para apresentação dos serviços da empresa, captação de leads via formulário integrado e área de pagamentos de clientes.

---

## 🚀 Como executar localmente

### Pré-requisitos
- Node.js (versão 18 ou superior)
- Gerenciador de pacotes (`npm`, `yarn`, `pnpm` ou `bun`)

### Passo a passo

1. Clone o repositório:
```bash
git clone [https://github.com/pedrosiqueirapb/autojade.git](https://github.com/pedrosiqueirapb/autojade.git)
```

2. Instale as dependências:
```bash
npm install
```

3. Inicie o servidor de desenvolvimento:
```bash
npm run dev
```

4. Acesse no navegador:
```
http://localhost:3000
```

## 📌 Principais recursos

- **Apresentação de serviços:** Módulos de automação, sites/landing pages e conteúdo visual com IA.
- **Captação de leads:** Formulário dinâmico integrado ao fluxo de triagem e contato inicial com o *lead*.
- **Páginas de pagamento:** Ambiente dedicado e restrito para checkout e formalização de clientes.
